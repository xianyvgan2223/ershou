# 06 · 单体接口：地图与面交点位

> 代码位置：`ershou-server`（Spring Boot 3.3.5 / MyBatis-Plus 3.5.9 / Sa-Token 1.39.0 / JDK21）。
> 模块包：`com.ershou.campus.module.map`。
> 基础路径：**`/api/v1`**（`MapController` 类级 `@RequestMapping("/api/v1")`，方法上再拼完整路径）；`AmapPageController` 类级为 **`/api/v1/map`**。
> 涉及表：`trade_point`（面交点），读取 `campus`（底图配置）、`item`（点位在售数 / 最低价）。
> 本文所有接口、字段、错误码均来自当前源码；源码未体现之处标注“以源码为准”。

## 1. 模块概览

| 项 | 说明 |
| --- | --- |
| 接口总数 | 11 个：`MapController` 8 个 + `AmapPageController` 3 个 |

| 高德配置 | `ershou.amap.js-key`（JS API key，公开 key）、`ershou.amap.js-security-code`（安全密钥）、`ershou.amap.web-key`（Web 服务 key，仅服务端用） |

### 1.1 高德 key 的边界（源码明确约束）

- **Web 服务 key（`ershou.amap.web-key`）绝不下发前端**，只用于服务端请求 `restapi.amap.com`（本项目仅逆地理编码）。
- JS API key 与 `securityJsCode` 属于“本来就会出现在网页源码里”的公开 key，会写进 `/api/v1/map/amap-html` 返回的 HTML；`/api/v1/map/amap-status` 只返回是否配置与长度，不返回 key 本身。
- 未配置 web-key 时 `/api/v1/map/regeo` 返回空数组，前端退化为手动填名称，不报错。

### 1.2 统一异常与错误码

`GlobalExceptionHandler` 的行为：`BizException` → `Result.fail(code, message)`（HTTP 通常仍为 200）；`NotLoginException` → `10002`；`@Valid` 校验失败 → `10001`（message 取字段注解提示）；其它未捕获异常 → `90001`。

| 枚举 | code | 默认 message | 本模块触发点 |
| --- | --- | --- | --- |
| `SUCCESS` | 0 | ok | 所有成功响应；高德调用失败也降级为成功 + 空数据 |
| `PARAM_ERROR` | 10001 | 参数校验失败 | 缺少 `campusId`/`name`/坐标；点位名超 30 字；`map/points` 的校区不存在 |
| `NOT_LOGIN` | 10002 | 未登录或登录已过期 | 三个 POST 与 `my-points` 内部 `StpUtil.checkLogin()` |
| `SYSTEM_ERROR` | 90001 | 系统开小差了，请稍后再试 | 未单独处理的异常（如缺少必填 query 参数的类型/绑定异常） |

> 本模块不存在运营审核接口；点位审核/停用/清理在 `module/admin`（`AdminAuditController` 的 `/api/v1/admin/audit/points*`、`AdminManageController` 的 `/api/v1/admin/trade-points/cleanup-empty`），不在此文档范围内。

## 2. 数据模型简表

### 2.1 `trade_point`（面交点）

DDL 见 `sql/schema.sql`。实体 `module/map/entity/TradePoint.java`，Mapper 仅继承 `BaseMapper<TradePoint>`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT PK AUTO | 点位 id |
| `campus_id` | BIGINT NOT NULL | 所属校区；所有列表/搜索按它过滤 |
| `name` | VARCHAR(64) NOT NULL | 点位名称；接口层额外限制 **≤30 字**（trim 后） |
| `source` | TINYINT NOT NULL DEFAULT 1 | **1=官方开通，2=用户提交，3=高德搜索落库** |
| `point_type` | TINYINT NOT NULL DEFAULT 9 | 1=门卫室旁 2=食堂 3=广场 4=快递站 5=教学楼大厅 6=校警室旁 7=宿舍区 9=其他 |
| `coord_x` / `coord_y` | DECIMAL(10,2) NULL | 自绘底图像素坐标（`campus.map_type=1` 用），与 lng/lat 二选一 |
| `lng` / `lat` | DECIMAL(10,7) NULL | 高德坐标（GCJ-02，`map_type=2` 用） |
| `available_period` | JSON NULL | 可用时段，如 `["08:00-22:00"]` |
| `safe_tags` | JSON NULL | 安全标签，如 `["监控","人流","照明"]` |
| `safety_score` | TINYINT NOT NULL DEFAULT 60 | 安全分 0–100；推荐与夜间过滤用 |
| `guide_text` | VARCHAR(255) NULL | 图文参照说明 |
| `status` | TINYINT NOT NULL DEFAULT 1 | **1=启用 0=停用**；所有读接口只取 `status=1` |
| `audit_status` | TINYINT NOT NULL DEFAULT 1 | **0=待审 1=通过 2=驳回**；但本模块读接口**不过滤审核状态**（新提交点位免审核，直接置 1） |
| `merge_group` | BIGINT NULL | 合并组 id（同名点合并，历史字段；当前写接口不做合并） |
| `deal_count` / `dispute_count` | INT NOT NULL DEFAULT 0 | 累计成交 / 纠纷 |
| `creator_id` | BIGINT NULL | 提交用户；`my-points` 按它过滤 |
| `created_at` / `updated_at` | DATETIME | 自动维护；空点位清理按 `created_at` 判断是否超过 7 天 |

### 2.2 关联数据

- `campus.map_type`：`1=自绘平面图`，`2=第三方地图`；`campus.map_config` 为 JSON（`{imgUrl,width,height,minZoom,maxZoom,center,polygon}`），仅 `GET /api/v1/map/points` 下发给前端。
- `item` 的“还有戏”状态 `0,1,2,3`（草稿/审核中/在售/已锁定）才计入点位 `itemCount`；`onSaleCount` 只统计 `status=2`（在售）。
- 搜索落库点位（`source=3`）在**任何**读场景都只有“挂上还有戏的商品”后才可见，避免搜过的地名刷屏。

### 2.3 `TradePointVO`

`id,name,type(=point_type),coordX,coordY,lng,lat,safetyScore,safeTags[],availablePeriod[],guideText,auditStatus,source,itemCount,onSaleCount,minPrice`；`itemCount`/`onSaleCount`/`minPrice` 仅在列表聚合接口中计算，单点返回（新建/我的点位）固定 `itemCount=0`。

## 3. `MapController` 接口（8 个）

### 1. 地图数据：底图 + 点位 + 每点位在售数
- **方法与路径**：`GET /api/v1/map/points`
- **鉴权**：公开
- **请求参数**：

  | 位置 | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- | --- |
  | query | `campusId` | Long | 是 | 校区 id |

- **请求体**：无
- **响应示例**：
  ```json
  {
    "code": 0,
    "message": "ok",
    "traceId": "a1b2c3",
    "data": {
      "mapType": 2,
      "mapConfig": {
        "center": { "lng": 110.416819, "lat": 25.311724 },
        "zoom": 15
      },
      "points": [
        {
          "id": 1,
          "name": "图书馆东门广场",
          "type": 3,
          "coordX": 520,
          "coordY": 310,
          "lng": 110.416819,
          "lat": 25.311724,
          "safetyScore": 85,
          "safeTags": ["监控", "人流", "照明", "座椅"],
          "availablePeriod": ["08:00-22:00"],
          "guideText": "从东门进入后直走约150米，广场旗杆旁",
          "auditStatus": 1,
          "source": 1,
          "itemCount": 3,
          "onSaleCount": 2,
          "minPrice": 35.00
        }
      ]
    }
  }
  ```
- **业务规则 / 校验**：
  - 校区不存在（`DictionaryCache.campus` 查不到）抛 `BizException(10001, "校区不存在")`。
  - `mapType`、`mapConfig` 直接取 `campus` 字段；`mapConfig` 不是合法 JSON 时置 `null`（JSON 序列化后字段省略）。
  - 点位只取该校区 `status=1`，且**只画“有商品”的点位**（`item` 状态 `0/1/2/3` 且 `prefer_point_id` 非空）；`source=3` 的点位必须已挂商品才出现。
  - `itemCount` 含审核中的商品；`onSaleCount` 仅 `status=2`；`minPrice` 取这些商品非空价格的最小值。
  - 结果按 `itemCount` 倒序；使用版本号缓存 `ershou:map:points:{campusId}:items:v{version}`，TTL 30 分钟；任何点位/商品写路径 `bumpMapVersion()` 后旧缓存立即不可达。
- **可能错误码**：`0`、`10001`（校区不存在）、`90001`（缺少 `campusId` 等未捕获绑定异常）

- **请求参数**：

  ```json
    "data": [
      {
        "id": 2,
        "name": "一食堂正门",
        "type": 2,
        "coordX": 380,
        "coordY": 470,
        "safetyScore": 80,
        "safeTags": ["人流", "照明"],
        "availablePeriod": ["07:00-21:00"],
        "auditStatus": 1,
        "source": 1,
        "itemCount": 4,
        "onSaleCount": 3,
        "minPrice": 12.50
      },
      {
        "id": 18,
        "name": "新宿舍楼门口",
        "type": 9,
        "lng": 110.4171,
        "lat": 25.3122,
        "safetyScore": 40,
        "safeTags": [],
        "availablePeriod": [],
        "auditStatus": 1,
        "source": 2,
        "itemCount": 0,
        "onSaleCount": 0
      }
    ]
  }
  ```
- **业务规则 / 校验**：
  - 与地图接口相反：**保留 0 商品的点位**（发布页/私聊选点必须能选到刚建、尚未挂商品的点位）。

  - **不过滤 `audit_status`**（产品定案自定义点位免审核；待审点位也返回）。
  - 结果按 `itemCount` 倒序；缓存 key `ershou:map:points:{campusId}:v{version}`，TTL 30 分钟，与地图接口是**两份独立缓存**。
  - 不校验校区是否存在：无效校区返回空数组。
- **可能错误码**：`0`、`90001`（缺少 `campusId`）

### 3. 面交点推荐 Top5
- **方法与路径**：`GET /api/v1/trade-points/recommend`
- **鉴权**：公开（可选登录：已登录时读取 userId，但当前算法未使用该值）
- **请求参数**：

  | 位置 | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- | --- |
  | query | `campusId` | Long | 是 | 校区 id |
  | query | `itemId` | Long | 否 | 商品 id；用于取该商品的 `preferPointId` 作为距离参考点 |

- **请求体**：无
- **响应示例**：
  ```json
  {
    "code": 0,
    "message": "ok",
    "data": [
      {
        "id": 4,
        "name": "校警室门口",
        "type": 6,
        "coordX": 300,
        "coordY": 220,
        "safetyScore": 95,
        "safeTags": ["监控", "值守", "照明"],
        "availablePeriod": ["00:00-23:59"],
        "auditStatus": 1,
        "source": 1,
        "itemCount": 2,
        "onSaleCount": 2,
        "minPrice": 20.00
      }
    ]
  }
  ```
- **业务规则 / 校验**：
  - 候选集来自 `cachedPoints(campusId)`（**含 0 商品点位**，与发布页口径一致）。
  - 夜间（`22:00` 之后或 `06:00` 之前，按服务器本地时间 `LocalTime.now()`）优先只保留 `safetyScore >= 85` 的点位；若过滤后为空则退回全部点位。
  - `itemId` 有值且商品存在、商品有 `preferPointId`、对应点位能查到且 `coordX` 非空时，以该点位 `coordX/coordY` 为参考计算距离。
  - 打分：`0.5 * 距离分 + 0.3 * 安全分 + 0.2 * 热度`；距离分无参考点或点位无 `coordX` 时为 `0.7`，否则 `max(0, 1 - 像素距离/800)`；安全分为 `safetyScore/100`（空则 `0.6`）；热度为 `min(itemCount/20, 1)`。
  - 按分数倒序取前 **5** 个；无候选返回空数组。
- **可能错误码**：`0`、`90001`（缺少 `campusId`）

### 4. 我附近的点位（Redis GEO 检索）
- **方法与路径**：`GET /api/v1/trade-points/nearby`
- **鉴权**：公开
- **请求参数**：

  | 位置 | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- | --- |
  | query | `campusId` | Long | 是 | 校区 id |
  | query | `lng` | Double | 是 | 用户经度，**必须是 GCJ-02**（浏览器 WGS-84 需前端转换） |
  | query | `lat` | Double | 是 | 用户纬度，GCJ-02 |
  | query | `radius` | Integer | 否 | 半径（米），默认 `500`，服务端夹在 `[50, 5000]` |
  | query | `limit` | Integer | 否 | 返回上限，默认 `20`，服务端夹在 `[1, 50]` |

- **请求体**：无
- **响应示例**：
  ```json
  {
    "code": 0,
    "message": "ok",
    "data": [
      {
        "id": 2,
        "name": "一食堂正门",
        "pointType": 2,
        "lng": 110.4171,
        "lat": 25.3122,
        "guideText": "一食堂正门台阶处，紧邻超市",
        "source": 1,
        "distanceMeters": 120
      }
    ]
  }
  ```
- **业务规则 / 校验**：
  - 全程走 Redis `GEOSEARCH`（`PointGeoIndex`），**不消耗任何高德配额**；坐标来自浏览器定位。
  - GEO 索引由 DB 重建：只收录该校区 `status=1` 且 `lng/lat` 非空的点位；索引 key `ershou:map:geo:{campusId}:v{version}`，TTL 6 小时；无索引时抢锁重建（锁 TTL 30 秒），抢不到锁的请求本次返回空。
  - 结果按距离升序、最多 `limit` 个；再回 DB 过滤 `status=1`，并剔除“`source=3` 且没有还有戏商品”的点位；已删除/不可见点位直接跳过，不报错。
  - 返回每项附带 `distanceMeters`（四舍五入到整数）；Redis 异常或检索失败降级为空数组，`code` 仍是 0。
  - 服务端不校验点位是否属于该校区以外的情况（索引本身按校区建立）。
- **可能错误码**：`0`、`90001`（缺少参数/类型错误）

### 5. 用户自定义点位提交（免审核）
- **方法与路径**：`POST /api/v1/trade-points/suggest`
- **鉴权**：需要登录（`StpUtil.checkLogin()`；路径虽在白名单，Controller 内部校验）
- **请求参数**：无 query/path 参数
- **请求体**：
  ```json
  {
    "campusId": 1,
    "name": "新宿舍楼门口",
    "lng": 110.4171,
    "lat": 25.3122,
    "guideText": "7 号楼东侧快递柜旁",
    "pointType": 9
  }
  ```
- **响应示例**：
  ```json
  {
    "code": 0,
    "message": "ok",
    "data": {
      "id": 18,
      "name": "新宿舍楼门口",
      "type": 9,
      "lng": 110.4171,
      "lat": 25.3122,
      "safetyScore": 40,
      "safeTags": [],
      "availablePeriod": [],
      "guideText": "7 号楼东侧快递柜旁",
      "auditStatus": 1,
      "source": 2,
      "itemCount": 0
    }
  }
  ```
- **业务规则 / 校验**：
  - `campusId` 非空、`name` 非空（`@NotNull` / `@NotBlank`），否则 `10001`。
  - `lng/lat` 与 `coordX/coordY` **至少提供一组**，否则 `10001 "请在地图上选点"`。
  - `name` trim 后长度 **≤30**，否则 `10001 "点位名称最多 30 个字"`（表字段为 VARCHAR(64)，接口层收紧）。
  - `pointType` 为空默认 `9`；`source=2`；`safetyScore=40`；`safeTags="[]"`；`status=1`；`auditStatus=1`（免审核直接通过）；`dealCount=0`、`disputeCount=0`；`creatorId=当前登录用户`。
  - **不做同名合并**：每次调用都 `insert` 新记录，点位 id/坐标独立；重复由运营后台删除。
  - 写入后 `CacheEvictor.pointChanged(id)`：删点位字典缓存并自增地图缓存版本号，避免别人看不到新点。
  - 返回单点 VO，`itemCount` 固定 0（不含在售统计）。
- **可能错误码**：`0`、`10001`、`10002`

  ```json
    "code": 0,
    "message": "ok",
    "data": {
      "id": 20,
      "name": "示例大学便利店",
      "type": 9,
      "lng": 110.4175,
      "lat": 25.3126,
      "safetyScore": 30,
      "safeTags": [],
      "availablePeriod": [],
      "guideText": "高德搜索：示例大学便利店",
      "auditStatus": 1,
      "source": 3,
      "itemCount": 0
    }
  }
  ```
- **业务规则 / 校验**：
  - 先按 `campusId + name(trim) + status=1` 查库（`LIMIT 1`）：
    - 命中则**直接复用，不落库、不再调用高德**；若原记录 `creatorId` 为空，则把当前用户写为 `creatorId`（否则他在 `my-points` 里看不到）；
    - 未命中才插入新记录。
  - 新建时 `source=3`（高德搜索落库）、`safetyScore=30`（搜索地点只是“可选地址”，不是推荐面交点）；其余默认值与接口 5 一致（`pointType` 默认 9、`auditStatus=1`、`status=1`、`safeTags="[]"`、`dealCount/disputeCount=0`）。
  - 仅**新建分支**执行接口 5 的坐标校验（经纬度或像素坐标至少一组）与名称长度 ≤30 校验；命中库内同名记录时直接复用，不再校验坐标/长度。
  - 新建分支写入后同样执行 `pointChanged` 失效缓存；命中复用分支不触发缓存失效（仅可能补写 `creatorId`）。
  - 该接口**只落库，不发起任何高德请求**；是否调用高德搜索由前端决定，库内命中可省搜索配额。
- **可能错误码**：`0`、`10001`、`10002`

### 8. 我提交过的点位（含待审，仅自己可见）
- **方法与路径**：`GET /api/v1/trade-points/my-points`
- **鉴权**：需要登录（`StpUtil.checkLogin()`）
- **请求参数**：

  | 位置 | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- | --- |
  | query | `campusId` | Long | 是 | 校区 id |

- **请求体**：无
- **响应示例**：
  ```json
  {
    "code": 0,
    "message": "ok",
    "data": [
      {
        "id": 18,
        "name": "新宿舍楼门口",
        "type": 9,
        "lng": 110.4171,
        "lat": 25.3122,
        "safetyScore": 40,
        "safeTags": [],
        "availablePeriod": [],
        "guideText": "7 号楼东侧快递柜旁",
        "auditStatus": 1,
        "source": 2,
        "itemCount": 0
      }
    ]
  }
  ```
- **业务规则 / 校验**：
  - 查询条件：`campus_id = campusId`、`creator_id = 当前用户`、`status = 1`，按 `id` 倒序。
  - **包含待审点位**（`audit_status=0`）以及复用搜索点位后被“认领”的点位；只查自己，不会泄露他人待审点位。
  - 返回每项 `itemCount=0`（不聚合在售统计）。
  - 不校验校区是否存在，无数据返回空数组。
- **可能错误码**：`0`、`10002`、`90001`

## 4. `AmapPageController` 接口（3 个）

### 9. 逆地理编码候选（服务端代理高德 Web 服务）
- **方法与路径**：`GET /api/v1/map/regeo`
- **鉴权**：公开
- **请求参数**：

  | 位置 | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- | --- |
  | query | `lng` | Double | 是 | 经度（GCJ-02） |
  | query | `lat` | Double | 是 | 纬度（GCJ-02） |

- **请求体**：无
- **响应示例**：
  ```json
  {
    "code": 0,
    "message": "ok",
    "data": [
      {
        "name": "示例大学便利店",
        "address": "示例路 1 号",
        "distanceMeters": 35,
        "isPoi": true
      },
      {
        "name": "示例路 1 号",
        "address": "",
        "distanceMeters": 0,
        "isPoi": false
      }
    ]
  }
  ```
- **业务规则 / 校验**：
  - 未配置 `ershou.amap.web-key` → 直接返回空数组（`code=0`），不报错。
  - 调 `https://restapi.amap.com/v3/geocode/regeo?key=<web-key>&location=<lng>,<lat>&radius=500&extensions=all&output=JSON`。
  - 高德 `status != "1"` 或解析失败：日志告警并返回**上次已解析的部分/空数组**，接口仍成功。
  - POI 按 `distance` 升序、名称去重、**最多 8 条**；`address` 为空时回退 `formattedAddress`；最后把 `formattedAddress` 作为兜底候选追加（`isPoi=false`、`distanceMeters=0`、`address=""`）。
  - 只消耗高德**基础 LBS 配额**（源码注释：约 15 万次/月，远宽于搜索 5000 次/月）；`web-key` 只在服务端使用，不下发前端。
  - 本接口返回的候选**不含 lng/lat**（与 HTML 页面内 `AMap.Geocoder` 的候选不同，后者会带 POI 坐标）。
  - 任何异常都降级为 `code=0 + []`，不会返回高德错误码。
- **可能错误码**：`0`、`90001`（缺少参数/类型错误）

### 10. 高德 key 是否已配置（不下发 key 本身）
- **方法与路径**：`GET /api/v1/map/amap-status`
- **鉴权**：公开
- **请求参数**：无
- **请求体**：无
- **响应示例**：
  ```json
  {
    "code": 0,
    "message": "ok",
    "data": {
      "configured": true,
      "hint": "高德地图可用",
      "jsKeyLength": 32,
      "securityCodeLength": 32
    }
  }
  ```
- **业务规则 / 校验**：
  - `configured = jsKey 非空 && securityCode 非空`；任一缺失则 `false`，同时输出 WARN 日志（该接口是移动端判断“能否显示真地图”的唯一依据）。
  - key 解析顺序：`ershou.amap.js-key` → 环境变量 `AMAP_JS_KEY` → 环境变量 `VITE_AMAP_JS_KEY`；安全密钥同理（`ershou.amap.js-security-code` → `AMAP_JS_SECURITY_CODE` → `VITE_AMAP_JS_SECURITY_CODE`）。
  - 只返回长度与提示，**绝不返回 key 内容**；`hint` 未配置时提示在项目根目录 `.env` 补 `AMAP_JS_KEY / AMAP_JS_SECURITY_CODE`。
  - 未配置时字段 `jsKeyLength`/`securityCodeLength` 为 `0`（不会省略，因为不是 null）。
- **可能错误码**：`0`

### 11. 移动端高德地图 HTML（自带 key，供 WebView 加载）
- **方法与路径**：`GET /api/v1/map/amap-html`
- **鉴权**：公开
- **请求参数**：

  | 位置 | 参数 | 类型 | 必填 | 说明 |
  | --- | --- | --- | --- | --- |
  | query | `campusId` | Long | 否 | 默认 `2`；页面据此拉 `/api/v1/map/points` |
  | query | `pickable` | boolean | 否 | 默认 `false`；`true` 时点击地图回传选点坐标 |
  | query | `focusPointId` | Long | 否 | 只画/点亮该点位（商品详情“在地图上看”） |
  | query | `wantRegeo` | boolean | 否 | 默认 `false`；选点时同时做 JS 逆地理编码 |
  | query | `mapPoints` | String | 否 | 已合并气泡的 JSON 数组字符串；仅用于展示，优先级高于服务端点位 |

- **请求体**：无
- **响应示例**（**不是 `Result` 包装**，直接返回 HTML）：
  ```http
  HTTP/1.1 200 OK
  Content-Type: text/html;charset=UTF-8
  Cache-Control: no-store

  <!doctype html>
  <html lang="zh-CN">…（含高德 loader、地图初始化、点位气泡脚本）…</html>
  ```
- **业务规则 / 校验**：
  - `ershou.amap.js-key` 为空时返回 200 的**降级 HTML**（灰字提示“后端未配置高德 key…，无法显示真地图”），不抛异常。
  - 正常页面：用 `AMapLoader`（`version=2.0`，插件 `AMap.Scale`、`AMap.Geocoder`）加载地图，内联 JS key 与 `securityJsCode`；**Web 服务 key 绝不出现**在 HTML 中。
  - 页面内部 `fetch('/api/v1/map/points?campusId=' + campusId)` 取底图配置与点位；只画有 `lng/lat` 的点位；`focusPointId > 0` 时只保留该点位（支持合并组 `ids` 匹配）并居中放大。
  - `mapPoints` 校验：必须形如 `[...]`、长度 ≤ 400000、能 JSON 解析，否则忽略并回退服务端点位；`</` 会被替换为 `<\/` 防止截断 `<script>`。
  - `pickable=true`：点击地图先打“水滴针”，再通过 `window.FlutterBridge.postMessage` 回传 `{type:'pick', lng, lat}`；`wantRegeo=true` 时额外用页面 JS `AMap.Geocoder`（半径 500、`extensions=all`）生成最多 8 个候选（按距离、去重，带 POI 的 `lng/lat`），随 `candidates` 一起回传。
  - 点位气泡点击回传 `{type:'select', pointId, ids}`（`ids` 为合并组内真实点位 id）；初始化完成回传 `{type:'ready', count, markerCount, merged}`。
  - 页面暴露给 Flutter `runJavaScript` 的钩子：`__ershouSel`、`__ershouCount`、`__ershouClicks`、`__ershouTap`、`__ershouFirstId`、`__ershouCenter`、`__ershouFocus`、`__ershouLocate`、`__ershouPickMark`、`__ershouClearPickMark`（以源码为准）。
  - 响应头固定 `Cache-Control: no-store`；key 写入 HTML 前经 `jsonSafe` 过滤（仅保留字母/数字/`_`/`-`）。
- **可能错误码**：无 JSON 错误码；配置缺失/地图脚本失败均以 HTML 降级呈现

## 5. 实现清单

### 5.1 需要实现的类（均在 `com.ershou.campus.module.map`）

| 类 | 职责 |
| --- | --- |
| `controller/MapController` | 8 个点位/地图读接口 + 3 个点位写接口（类级 `/api/v1`） |
| `controller/AmapPageController` | 逆地理编码代理、key 状态、地图 HTML（类级 `/api/v1/map`） |
| `service/TradePointService` | 点位查询/推荐/附近/新增/搜索落库/我的点位/空点位清理；缓存编排 |
| `service/PointGeoIndex` | Redis GEO 索引的检索、按 DB 重建、重建锁 |
| `entity/TradePoint` | `@TableName("trade_point")`，`@TableId(type=AUTO)` |
| `mapper/TradePointMapper` | `extends BaseMapper<TradePoint>`，无常规定制 SQL |
| `dto/PointSuggestDTO` | `campusId`(`@NotNull`)、`name`(`@NotBlank`)、`coordX/coordY`、`lng/lat`、`guideText`、`pointType`(默认 9) |
| `vo/TradePointVO` | 点位返回模型（含 `itemCount/onSaleCount/minPrice`） |
| `vo/MapDataVO` | `mapType`、`mapConfig`、`points` |

### 5.3 配置项（`application.yml`）

```yaml
ershou:
  cache:
    map-points-ttl: 30m        # 点位列表缓存 TTL
  amap:
    js-key: ${AMAP_JS_KEY:}                 # 公开 JS key，可下发（写入 HTML）
    js-security-code: ${AMAP_JS_SECURITY_CODE:}
    web-key: ${AMAP_WEB_KEY:}               # 仅服务端，绑 IP 白名单，绝不下发
```

- `SaTokenConfig` 白名单必须包含 `/api/v1/map/**`、`/api/v1/trade-points/**`（否则读接口会被要求登录）。
- 高德 Web 服务调用可选加缓存/降级（源码当前未对 `/map/regeo` 做 Redis 缓存，仅异常降级为空数组）。
- Redis 不可用时：点位列表回源 DB（`JsonCache` 降级为未命中），附近检索返回空数组（`PointGeoIndex` 捕获异常）。
