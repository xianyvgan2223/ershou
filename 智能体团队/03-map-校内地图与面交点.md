## 2. 功能边界

- **做什么**：① 双模式底图：`campus.map_type=2` + 本地配了高德 Key → 高德真地图（`AmapCampusMap.vue`），否则退回 Leaflet 自绘平面图（`CampusMap.vue`）；移动端由后端下发高德 HTML 给 WebView。② 面交点（`trade_point`）的增/选/展示：地图气泡、侧栏列表、发布页与私聊页选点弹窗；点位两种可见性（地图只画有商品的 / 发布页含 0 商品的）。③ 100 米内相近点位的**展示层合并**（不落库）。④ 选点针两端同款画法。⑤ 点位聚合缓存与版本号失效、空点位清理（定时 + 手动）。⑥ 移动端「我附近」窗口（Redis GEO 检索 + 可折叠）。
- **不做什么**：① **不做自由地点搜索**（高德基础搜索仅 5000 次/月，见 `功能清单.md:123`；`utils/placeCache.ts` 只缓存"已搜过的关键词"，不新增搜索入口）。② **不做同名点位合并**（`merge_group` 逻辑已删除，改前端 100m 展示合并）。③ 地图页**不提供新增点位入口**（新增只在发布/交易流程做）。④ 点位与商品的小窗/列表**不决定交易关系**：商品与面交单永远引用精确 `pointId`，合并只影响"看和选"。⑤ 商品模块的搜索/分页本体、面交单状态机、运营后台页面不归本成员（只核实与地图相关的接口参数与调用点）。
