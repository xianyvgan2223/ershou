### 8.3 QA 附带发现（**非本轮 T18/T19 改动引起**，建议 Lead 裁决是否另开修复项）
- **现象**：QA 后端日志在 `2026-10-18T16:00:00.022` 出现 1 行 `ERROR ... Unexpected error occurred in scheduled task`，堆栈为
  `java.lang.NullPointerException: Cannot invoke "java.lang.Long.longValue()" because the return value of "ScheduledTasks.parseLong(String)" is null at ScheduledTasks.flushViewCounts(ScheduledTasks.java:191)`
- **证据**：`.build/mobile/logs/backend-20261018-155823.out.log`（ERROR 行 + 完整堆栈）；`ScheduledTasks.java:191` `long delta = parseLong(redis.opsForValue().get(RedisKeys.itemView(itemId)));`（键缺失时 `parseLong` 返回 null → 拆箱 NPE，见 `:248-255`）
- **归因**：`git diff` 显示 T19 对 `ScheduledTasks.java` 的改动**只**在 `expireItems()` 开头加了限时开关早退（diff 已核对），`flushViewCounts` 为既有代码。触发条件推测为**两个后端实例共享同一 Redis**（用户 8080 IDEA 实例 + QA 18080）：一方 flush 后删除 `ershou:item:view:{id}` 并清理 dirty 集合，另一方在读到旧 dirty 集合后取不到计数键 → null。单实例环境下不触发。
- **影响**：该次浏览量回写中断（数据仍在 Redis 计数里，下一轮 10 分钟 cron 会重试，不丢计数），但会产生 ERROR 日志告警。
- **建议修法（不属本轮范围，由 Lead 决定）**：`:191` 改为 `Long delta = parseLong(...); if (delta == null || delta <= 0) { stale.add(raw); continue; }`（与 `:186-190` 同款防护）。QA 未改任何源码。

## 10. 首轮试跑 2 FAIL 的自检说明（证明是 QA 脚本缺陷，已修，产品零改动）

首次试跑（15:51:46）出现 2 FAIL、2 WARN（另 1 条断言抛参数绑定异常），逐条定位后均为**脚本断言缺陷**，产品代码未改一行。首次试跑的 console 输出随后被正式复跑覆盖（同一文件 `verify-round4-console.log`），此处按当时记录列出根因与修法；**正式证据以 §1~§7 的复跑与 JSON 为准**：

| 首轮现象 | 根因 | 修法（只改 QA 脚本） |
| --- | --- | --- |
| `F1 flutter analyze exit=0` FAIL（error=0, warning=0） | 本机 Flutter 3.44 的 analyze 因既有 156 条 info lint 返回 exit=1；断言误把 exit=0 当门槛 | 改为"完成 + **0 error**（设计口径）"，info 计数降为 WARN 提示 |
| `V8 首页找到「严选」入口` FAIL（文本里明明有「严选」） | 「严选」入口是 `content-desc` 的 View 节点，旧实现只读 `text` 属性 | `Find-UiText/Get-UiTexts` 同时读 `text` + `content-desc` |
| `V9/V10` WARN（滑不动、进不去平台页） | 滑动坐标写死 `540,1800`，而真机是 **720×1600**，起点在屏幕外 | 改为 `wm size` 动态取分辨率后按比例滑动（并支持 8 次下滑找角标） |
| `V6` 断言抛参数绑定异常（`Check` 收到 String） | `'启动 App（... ' + $Activity + '）'` 命令参数位置漏了整体括号，`+` 被当成独立参数 | 用 `(...)` 包住拼接 |

修复后**未再改动任何产品代码**，于 15:58:19 起完整复跑一次，得到 §1 的 108 PASS / 0 FAIL。该自检过程也说明脚本的每一步都有真实设备/接口输出支撑，而非"默认通过"。
