## 一、A 部分：开发期取消商品限时（`item-member` 负责，T19）

### 1.1 后端可配置开关（**不改表结构**）
`application.yml` 的 `ershou:` 下新增（保持默认值 = 现在的行为，生产不受影响）：
```yaml
  item:
    # 商品有效期（天）：发布 / 重新上架时写入 expire_at = now + valid-days
    valid-days: ${ITEM_VALID_DAYS:7}
    # 商品限时总开关：false 时发布/重新上架**不写 expire_at（NULL）**，过期任务跳过
    validity-enabled: ${ITEM_VALIDITY_ENABLED:true}
    # 过期任务 cron（原样保留可配置）
    expire-cron: ${ITEM_EXPIRE_CRON:0 30 * * * ?}
```
`ItemService`（`module/item/service/ItemService.java`）：
- 新增 `@Value("${ershou.item.validity-enabled:true}") private boolean validityEnabled;`
- 发布 `publish(...)`（约 `:335`）：`item.setExpireAt(validityEnabled ? LocalDateTime.now().plusDays(validDays) : null);`
- 重新上架 `relist(...)`（约 `:521`）：同样改为条件写入（关闭时 `null`）
- 新增 `public boolean isValidityEnabled() { return validityEnabled; }`（给定时任务用）
- 其余逻辑（审核、限额、锁库、状态机）**一律不动**

`ScheduledTasks.expireItems()`（`module/system/task/ScheduledTasks.java`，约 `:127`）：
- 方法开头：`if (!itemService.isValidityEnabled()) { log.debug("[task][expire-item] 商品限时已关闭（ershou.item.validity-enabled=false），跳过本轮"); return; }`

`.env.example` 追加（带注释）：
```
# 商品是否限时下架（开发期可置 false 关闭，便于测试/演示）
ITEM_VALIDITY_ENABLED=true
# 商品有效期（天）
ITEM_VALID_DAYS=7
```
`.env`（gitignore，本地开发配置）由 Lead 改为 `ITEM_VALIDITY_ENABLED=false`、`ITEM_VALID_DAYS=36500`（双保险：即使误开任务，到期也在 100 年后）。

### 1.2 过期商品批量重新上架 `sql/dev-relist-expired.sql`（新建，幂等）
```sql
-- 开发期数据修复：把「已过期(7)」的商品全部重新上架；平台商品同样清空到期时间
UPDATE item SET status=2, expire_at=NULL, published_at=NOW(), updated_at=NOW()
 WHERE status=7;
UPDATE item SET expire_at=NULL, updated_at=NOW()
 WHERE seller_type=2 AND status IN (2,4);
```
- 只动 `status=7`（已过期），不动 4 已售出 / 5 已下架 / 3 锁定；可重复执行（第二遍影响 0 行）。
- 执行方式：由 **Lead 执行**（item-member 不写库），执行后验证 `SELECT status,COUNT(*)`：status=2 应为 16（13 个人 + 3 平台）、status=7 应为 0。

### 1.3 前端对 `expireAt=NULL` 的兼容（只读核对，不改代码）
- Web：`ItemVO.expireAt?: string|null`；`expireText/expireUrgent` 需对 null/undefined 返回空，不得出现"还剩 null 天"。若发现会报错，由 `item-member` 在**只读核对后报告 Lead**（跨端改动另派 web 负责人，不能自己改）。
- 移动端：`Item.fromJson` 已 `?? ''`，`daysLeft` 对空串返回 null，`my_items_page` 已 `if (... && daysLeft != null)` → 安全；本轮 **app-member** 顺手在商品卡/详情对 `daysLeft == null` 不渲染倒计时。

### 2.2 页面结构（`platform_page.dart`）
- `AppBar`：标题「平台严选」，返回按钮；右上角刷新。
